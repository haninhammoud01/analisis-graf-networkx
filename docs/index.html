📖 Tentang Project

Project ini adalah tugas mata kuliah Web Structure Mining yang menganalisis struktur graf dari halaman web menggunakan library networkx di Python. Tugas dibagi menjadi 2 notebook:

  • Notebook 1 - Analisis graf 5 simpul (tak berarah & berarah): matriks ketetanggaan, degree, distribusi derajat, derajat rata-rata, density, lintasan terpendek, dan koefisien klasterisasi.

📐 Rumus PageRank (Bing Liu, Chapter 7.3)

PR(i) = (1 − d) / N + d · ∑(j,i) ∈ E PR(j) / Dout(j)
  • d = damping factor (default 0.85)
  • N = jumlah simpul
  • Dout(j) = out-degree dari simpul j
  • PR(j) = PageRank simpul j

Intuisi (PPT dosen - Rank Prestise & PageRank): Setiap simpul membagi PageRank-nya secara merata ke semua simpul yang ditautnya. Simpul yang ditaungi banyak simpul berprestise akan mendapat PageRank tinggi.

💡 Konsep Teori (Ringkasan)

  • Graf G=(V,E): pasangan terurut himpunan simpul V dan sisi E.
  • Graf Tak Berarah: sisi (a,b)=(b,a) - simetris. Contoh: koautor, jalan.
  • Graf Berarah: sisi (a,b) ≠ (b,a). Contoh: hyperlink WWW, follow Twitter.
  • Degree: jumlah sisi yang terhubung dengan simpul.
  • In-degree / Out-degree: busur masuk / keluar (khusus graf berarah).
  • Adjacency Matrix: matriks N×N, Aij=1 jika ada sisi i→j.
  • Density: L / Lmax - proporsi sisi yang ada.
  • Clustering Coefficient: seberapa erat tetangga simpul saling terhubung.
  • PageRank: ukuran pentingnya simpul berdasarkan struktur tautan.

🔀 Bentuk Representasi Graf

Satu graf bisa direpresentasikan dalam 4 bentuk berbeda:

RepresentasiUkuran MemoryKelebihan
Adjacency ListO(N + L)Efisien untuk graf sparse
Edge ListO(L)Paling ringkas, mudah disimpan
Adjacency MatrixO(N²)Cepat cek sisi, aljabar matriks
Incidence MatrixO(N × L)Analisis simpul-sisi
