Analisis PageRank pada Graf Berarah 4 Simpul

Tugas Web Structure Mining - PageRank & Representasi Graf

Notebook ini:

  • Membuat graf berarah (directed graph) dengan 4 simpul menggunakan networkx.
  • Menampilkan berbagai bentuk representasi graf (adjacency list, edge list, adjacency matrix, incidence matrix).
  • Menghitung PageRank masing-masing simpul menggunakan nx.pagerank().

    • Referensi PPT Dosen

    Materi ini mengacu pada PPT "Web Structure Mining" bagian:
    • 1. Mendeskripsikan Graf: Terminologi dan Metrik - matriks ketetanggaan & representasi graf.
    • 2.2 Prestise - Rank Prestise & PageRank (rumus dari Bing Liu, Chapter 7.3):
    PR(i) = \frac{(1 - d)}{N} + d \sum_{(j,i) \in E} \frac{PR(j)}{D_{out}(j)}

    dengan:

    • d = damping factor (biasanya 0.85)
    • N = jumlah simpul
    • D_out(j) = out-degree dari simpul j
    • PR(j) = PageRank simpul j
    Intuisi: setiap simpul j membagi PageRank-nya secara merata ke semua simpul yang ditautnya.

    3. Bentuk Representasi Graf

    Sebuah graf dapat direpresentasikan dalam beberapa bentuk yang berbeda. Masing-masing bentuk punya keunggulan:

    • Adjacency List - efisien untuk graf sparse (jarang).
    • Edge List - efisien untuk penyimpanan & pertukaran data.
    • Adjacency Matrix - mudah untuk perhitungan matematis (aljabar matriks).
    • Incidence Matrix - berguna untuk analisis hubungan simpul-sisi.
    Kita akan tampilkan keempatnya.

    3.1 Adjacency List (Daftar Ketetanggaan)

    Adjacency list menyimpan, untuk setiap simpul, daftar simpul tujuan (successor) dari simpul tersebut. Untuk graf berarah, kita tampilkan out-neighbors (simpul yang ditaut oleh simpul sumber).

    3.4 Incidence Matrix (Matriks Insidensi)

    Incidence matrix I berukuran N x L (jumlah simpul × jumlah sisi). Untuk graf berarah (PPT: definisi sisi berarah):

    • I_ij = -1 jika sisi j keluar dari simpul i
    • I_ij = +1 jika sisi j masuk ke simpul i
    • I_ij = 0 jika tidak terkait

    In [16]:
    # Ambil incidence matrix (oriented=True untuk graf berarah)

# Nama sisi
edge_labels = [f'e{i+1}({u}->{v})' for i, (u, v) in enumerate(G.edges())]
df_I = pd.DataFrame(I_mat, index=nodes, columns=edge_labels, dtype=int)
print('Incidence Matrix (Matriks Insidensi):')
print('=' * 70)
print(df_I)
print('=' * 70)
print('\nKonvensi: -1 = sisi keluar dari simpul, +1 = sisi masuk ke simpul')
print(f'Shape: {I_mat.shape} = ({G.number_of_nodes()} simpul) x ({G.number_of_edges()} sisi)')

    5. Konsep PageRank

    5.1 Rumus PageRank (Bing Liu, Chapter 7.3)

    PR(i) = \frac{(1 - d)}{N} + d \sum_{(j,i) \in E} \frac{PR(j)}{D_{out}(j)}

    Intuisi (PPT: Rank Prestise dan PageRank):

    • Setiap simpul j memiliki 'suara' sebesar PR(j).
    • Suara ini dibagi rata ke semua target tautannya, yaitu dibagi D_out(j).
    • Simpul i menerima suara dari semua simpul j yang menautkannya: Σ PR(j)/D_out(j).
    • d (damping factor) = 0.85 = proporsi waktu user mengikuti link (vs. lompat ke halaman acak).
    • (1-d)/N = probabilitas user lompat ke halaman acak (teleportation).

    5.2 Algoritma Iteratif

    PageRank dihitung secara iteratif:

  • Inisialisasi: PR(i) = 1/N untuk semua simpul.
  • Update dengan rumus di atas untuk semua simpul.
  • Ulangi sampai konvergen (perubahan sangat kecil).

    • 6. Menghitung PageRank dengan NetworkX

    NetworkX menyediakan fungsi nx.pagerank() yang menggunakan algoritma power iteration. Default damping factor = 0.85 sesuai standar Google.

    In [22]:
    # Hitung PageRank dengan networkx
pagerank = nx.pagerank(G, alpha=0.85)  # alpha = damping factor

print('Hasil PageRank (networkx, alpha=0.85):')
print('-' * 40)
for n in nodes:
    print(f'  PR({n}) = {pagerank[n]:.6f}')
print('-' * 40)
print(f'  Total = {sum(pagerank.values()):.6f}')
print('\nCatatan: Total PageRank = 1 (karena ternormalisasi).')

    6.1 Iterasi Manual PageRank (Proses Step-by-Step)

    Supaya lebih paham, berikut iterasi manual PageRank untuk beberapa langkah. Inisialisasi: PR(i) = 1/N = 0.25 untuk semua simpul.

    In [24]:
    # Iterasi manual PageRank untuk menunjukkan proses
d = 0.85  # damping factor
N = G.number_of_nodes()

# Inisialisasi: setiap simpul dapat 1/N
pr = {n: 1/N for n in nodes}

print(f'Inisialisasi: PR(A)=PR(B)=PR(C)=PR(D) = 1/N = 1/{N} = {1/N:.4f}')
print()

# Iterasi sebanyak 15 kali
for it in range(1, 16):
    new_pr = {}
    for i in nodes:
        # Cari in-neighbors simpul i (simpul j yang menaut ke i)
        in_neighbors = list(G.predecessors(i))
        inflow = 0.0
        for j in in_neighbors:
            inflow += pr[j] / G.out_degree(j)
        new_pr[i] = (1 - d) / N + d * inflow
    pr = new_pr
    print(f'Iter {it:2d} | ' + ' | '.join(f'PR({n})={pr[n]:.6f}' for n in nodes) + f' | Sum={sum(pr.values()):.6f}')

print()
print('Hasil setelah 15 iterasi (manual):')
for n in nodes:
    print(f'  PR({n}) = {pr[n]:.6f}')

    8. Interpretasi Hasil

    Beberapa pengamatan dari hasil PageRank:

  • Simpul C memiliki PageRank tertinggi (0.3710). Ini wajar karena C ditaungi oleh 3 simpul (A, B, D) - in-degree-nya paling tinggi. Makin banyak simpul yang menautkannya, makin tinggi PageRank (PPT: Prestise Derajat).

  • Simpul A menempati peringkat kedua (0.2781). Walaupun in-degree-nya sama dengan B dan D (yaitu 2 untuk A, 1 untuk B dan D), A menerima tautan dari simpul-simpul yang juga berprestise tinggi (C dan D), sehingga 'suara' yang masuk lebih berbobot (PPT: Rank Prestise).

  • Simpul B paling rendah PageRank-nya (0.1557) karena hanya ditauti oleh A (satu simpul) dan tidak punya banyak jalur masuk lain.

  • Damping factor d=0.85 berarti 85% dari 'suara' setiap simpul mengikuti tautan keluar (mengikuti link), dan 15% dibagi rata ke semua simpul (teleportation). Inilah yang memastikan total PageRank tetap = 1 dan graf tanpa dangling node tetap konvergen.
