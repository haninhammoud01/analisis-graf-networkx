Analisis Graf Berarah dan Tak Berarah dengan NetworkX

Tugas Web Structure Mining

Notebook ini melakukan analisis sederhana terhadap dua buah graf yang masing-masing memiliki 5 simpul (vertex):

  • Graf Tak Berarah (Undirected Graph)
  • Graf Berarah (Directed Graph)

    • Untuk masing-masing graf akan dihitung:

    • Matriks Ketetanggaan (Adjacency Matrix)
    • Derajat (Degree) tiap simpul - termasuk in-degree dan out-degree untuk graf berarah
    • Distribusi Derajat (Degree Distribution)
    • Derajat Rata-rata (Average Degree)
    • Kepadatan Graf (Graph Density)
    • Panjang Lintasan Terpendek (Shortest Path) & Rata-ratanya
    • Koefisien Klasterisasi (Clustering Coefficient) tiap simpul dan rata-ratanya

    Referensi PPT Dosen

    Materi pada notebook ini mengikuti konsep yang dibahas pada slide "Web Structure Mining" dari dosen, khususnya pada bagian:
    • Mendeskripsikan Graf: Terminologi dan Metrik - definisi graf, simpul, sisi berarah/tak berarah, matriks ketetanggaan, derajat, in-degree, out-degree.
    • Distribusi Derajat & Derajat Rata-rata - rumus rata-rata derajat untuk graf berarah dan tak berarah.
    • Kepadatan Graf - rumus L / L_maks dengan L_maks = N(N-1) untuk graf berarah dan L_maks = N(N-1)/2 untuk graf tak berarah.
    • Koefisien Klasterisasi - C_i = 2 k_i / (d_i (d_i - 1)), mengukur seberapa erat tetangga sebuah simpul saling terhubung.
    • Lintasan & Jalur Terpendek - definisi lintasan, jarak, diameter, dan rata-rata panjang lintasan terpendek.
    Sumber: PPT "Web Structure Mining" - Bab Mendeskripsikan Graf: Terminologi dan Metrik.

    2. Graf Tak Berarah (Undirected Graph)

    2.1 Membuat Graf

    Pada graf tak berarah, sisi (a, b) sama dengan (b, a) (simetris). Contoh nyata: tautan koautor, jalan umum (PPT: Graf Tak Berarah).

    Kita akan membuat graf dengan 5 simpul A, B, C, D, E dan 6 sisi tak berarah sebagai berikut:

    Sisi
    (A,B)
    (A,C)
    (B,C)
    (B,D)
    (C,E)
    (D,E)
    In [5]:
    # Membuat graf tak berarah dengan 5 simpul
G = nx.Graph()  # Graph() => graf tak berarah
G.add_edges_from([
    ('A', 'B'),
    ('A', 'C'),
    ('B', 'C'),
    ('B', 'D'),
    ('C', 'E'),
    ('D', 'E'),
])

print('Simpul (V):', list(G.nodes()))
print('Sisi  (E):', list(G.edges()))
print('Jumlah simpul (N) :', G.number_of_nodes())
print('Jumlah sisi   (L) :', G.number_of_edges())

    2.3 Matriks Ketetanggaan (Adjacency Matrix)

    Matriks ketetanggaan A berukuran N x N dengan A_ij = 1 jika ada sisi antara simpul i dan j, dan A_ij = 0 jika tidak terhubung. Untuk graf tak berarah, matriksnya simetris (A_ij = A_ji) (PPT: Matriks Ketetanggaan untuk Graf Berarah dan Tak Berarah).

    2.5 Derajat Rata-rata (Average Degree)

    Untuk graf tak berarah, derajat rata-rata adalah 2L / N (PPT: Derajat Rata-rata), atau bisa juga dihitung sebagai rata-rata derajat semua simpul.

    2.7 Kepadatan Graf (Graph Density)

    Untuk graf tak berarah, jumlah maksimum sisi L_maks = N(N-1)/2 (karena setiap sisi dihitung satu kali). Density = L / L_maks (PPT: Kepadatan Graf).

    In [18]:
    L_max_und = N * (N - 1) / 2
density_und_manual = L / L_max_und
density_und_nx = nx.density(G)

print(f'Jumlah sisi yang ada      L       = {L}')
print(f'Jumlah sisi maksimum      L_maks  = N*(N-1)/2 = {N}*{N-1}/2 = {L_max_und:.0f}')
print(f'Density (manual)                  = L/L_maks = {L}/{int(L_max_und)} = {density_und_manual}')
print(f'Density (nx.density)              = {density_und_nx}')

    2.8 Lintasan Terpendek (Shortest Path) & Rata-rata

    Jarak antara dua simpul adalah jumlah sisi sepanjang jalur terpendek yang menghubungkan keduanya. Jika tidak terhubung, jaraknya tak hingga. Rata-rata panjang lintasan terpendek = = (1 / (N(N-1))) Σ d_ij (PPT: Jalur Terpendek / Jarak dan Diameter Jaringan dan Jarak Rata-rata).

    In [20]:
    # Hitung panjang lintasan terpendek untuk semua pasangan simpul
lengths_und = dict(nx.all_pairs_shortest_path_length(G))

# Tampilkan sebagai matriks jarak
print('Matriks Jarak (Shortest Path Lengths) - Graf Tak Berarah:')
header = '     ' + '  '.join(f'{n:>3}' for n in nodes_und)
print(header)
for n1 in nodes_und:
    row = [lengths_und[n1].get(n2, 'inf') for n2 in nodes_und]
    print(f'  {n1}: ' + '  '.join(f'{v:>3}' for v in row))

    2.9 Koefisien Klasterisasi (Clustering Coefficient)

    Koefisien klasterisasi C_i mengukur seberapa banyak tetangga simpul i yang saling terhubung. Rumus (PPT: Koefisien Klasterisasi):

    C_i = \frac{2 \cdot k_i}{d_i (d_i - 1)}

    dengan k_i = jumlah sisi di antara tetangga simpul i, dan d_i = derajat simpul i. Nilai C_i berada dalam [0, 1].

    In [23]:
    print('Koefisien Klasterisasi tiap simpul (Graf Tak Berarah):')
print('-' * 50)
for node in nodes_und:
    cc = nx.clustering(G, node)
    d = G.degree(node)
    print(f'  C({node}) = {cc:.4f}   (degree = {d})')

avg_cc_und = nx.average_clustering(G)
print('-' * 50)
print(f'Rata-rata koefisien klasterisasi = {avg_cc_und:.4f}')
    Out [23]:
    Koefisien Klasterisasi tiap simpul (Graf Tak Berarah):
--------------------------------------------------

  C(D) = 0.0000   (degree = 2)

    3. Graf Berarah (Directed Graph)

    3.1 Membuat Graf

    Pada graf berarah (digraf), sisi (a, b) berbeda dengan (b, a). Sisi berarah disebut juga busur (arc). Contoh nyata: hyperlink di WWW, mengikuti di Twitter, panggilan telepon (PPT: Graf Berarah).

    Kita akan membuat graf berarah dengan 5 simpul A, B, C, D, E dan 7 busur (sisi berarah) sebagai berikut:

    (C,A)C → A
    (B,D)B → D
    (D,C)D → C
    (C,E)C → E
    (E,D)E → D

    3.4 Derajat (In-degree, Out-degree, Total Degree)

    Pada graf berarah kita membedakan:

    • In-degree k_in(v) = Σ a_ji : jumlah busur yang masuk ke simpul v
    • Out-degree k_out(v) = Σ a_ij : jumlah busur yang keluar dari simpul v
    • Total derajat k(v) = k_in(v) + k_out(v)
    Definisi (PPT: Derajat):
    • Source: simpul dengan k_in = 0 dan k_out > 0
    • Sink: simpul dengan k_out = 0 dan k_in > 0

    In [33]:
    print('Derajat masing-masing simpul (Graf Berarah):')
print('-' * 55)
print(f'{"Simpul":<10}{"In-degree":<12}{"Out-degree":<12}{"Total":<8}')
print('-' * 55)
for node in nodes_dir:
    in_d = D.in_degree(node)
    out_d = D.out_degree(node)
    total = in_d + out_d
    print(f'{node:<10}{in_d:<12}{out_d:<12}{total:<8}')
print('-' * 55)

# Identifikasi source dan sink
sources = [n for n in nodes_dir if D.in_degree(n) == 0 and D.out_degree(n) > 0]
sinks = [n for n in nodes_dir if D.out_degree(n) == 0 and D.in_degree(n) > 0]
print(f'Source (k_in=0, k_out>0) : {sources if sources else "tidak ada"}')
print(f'Sink   (k_out=0, k_in>0) : {sinks if sinks else "tidak ada"}')

    3.5 Derajat Rata-rata (Average Degree)

    Untuk graf berarah, derajat rata-rata adalah L / N (in-degree rata-rata = out-degree rata-rata = L/N), atau total derajat rata-rata = 2L/N (PPT: Derajat Rata-rata).

    In [35]:

print(f'Total in-degree              = {total_in}')
print(f'Total out-degree             = {total_out}')
print(f'Average in-degree  = L/N     = {L_d}/{N_d} = {L_d/N_d}')
print(f'Average out-degree = L/N     = {L_d}/{N_d} = {L_d/N_d}')
print(f'Average total degree= 2L/N   = 2*{L_d}/{N_d} = {2*L_d/N_d}')

    3.7 Kepadatan Graf (Graph Density)

    Untuk graf berarah, jumlah maksimum sisi L_maks = N(N-1) (karena setiap simpul dapat terhubung ke N-1 simpul lain secara berarah). Density = L / L_maks (PPT: Kepadatan Graf).

    In [40]:
    L_max_dir = N_d * (N_d - 1)
density_dir_manual = L_d / L_max_dir
density_dir_nx = nx.density(D)

    3.8 Lintasan Terpendek (Shortest Path) & Rata-rata

    Pada graf berarah, lintasan hanya boleh mengikuti arah busur. Akibatnya, jarak dari A ke B umumnya berbeda dengan jarak dari B ke A (PPT: Jalur Terpendek / Jarak).

    In [42]:
    # Hitung panjang lintasan terpendek untuk semua pasangan (mengikuti arah)
lengths_dir = dict(nx.all_pairs_shortest_path_length(D))

print('Matriks Jarak (Shortest Path Lengths) - Graf Berarah:')
header = '     ' + '  '.join(f'{n:>3}' for n in nodes_dir)
print(header)
for n1 in nodes_dir:
    row = []
    for n2 in nodes_dir:
        if n1 == n2:
            row.append(0)
        elif n2 in lengths_dir.get(n1, {}):
            row.append(lengths_dir[n1][n2])
        else:
            row.append('inf')
    print(f'  {n1}: ' + '  '.join(f'{v:>3}' for v in row))

print('\nCatatan: matriks TIDAK simetris karena lintasan harus mengikuti arah busur.')

    5. Kesimpulan

  • Matriks Ketetanggaan: graf tak berarah menghasilkan matriks simetris, sedangkan graf berarah menghasilkan matriks yang umumnya tidak simetris.
  • Derajat: pada graf berarah, derajat dibagi menjadi in-degree dan out-degree. Total derajat = in-degree + out-degree.
  • Kepadatan: rumus berbeda - L / (N(N-1)/2) untuk tak berarah, L / (N(N-1)) untuk berarah. Karena denominator lebih besar pada graf berarah, density graf berarah biasanya lebih kecil untuk jumlah sisi yang sama.
  • Lintasan Terpendek: pada graf berarah, jarak i → j tidak sama dengan j → i. Rata-rata lintasan terpendek pun biasanya lebih panjang pada graf berarah.
  • Koefisien Klasterisasi: mengukur seberapa erat tetangga sebuah simpul saling terhubung. NetworkX mendukung perhitungan ini untuk graf berarah maupun tak berarah.
